Vos partages réseau.
Montés en un clic.

ShareMan trouve les serveurs NFS et SMB de votre réseau local
et monte leurs partages sur votre Mac. Sans sudo, sans configuration.

Installer ShareMan Voir le code source ›

Pour macOS 13 Ventura ou plus récent.

Il trouve.

Bonjour et un scan rapide du sous-réseau repèrent vos serveurs en quelques secondes. NFS d’abord, SMB ensuite.

Il liste.

Les exports NFS et les partages SMB de chaque serveur s’affichent aussitôt, avec les clients autorisés.

Il monte.

Un clic, et le partage apparaît dans /Volumes, comme avec le Finder. Le trousseau fournit les mots de passe.

Une fenêtre.
Ou une ligne de commande.

L’application affiche les serveurs à gauche et leurs partages à droite. Choisissez, cliquez sur Monter, c’est tout.

Vous préférez le Terminal ? L’outil shareman fait la même chose, et sait aussi répondre en JSON pour vos scripts.

Un serveur NFS discret qui ne s’annonce pas ? Le scan approfondi interroge directement rpcbind pour le débusquer.

Installation

Il vous faut Xcode, ou simplement les Command Line Tools (xcode-select --install).

  1. Récupérez le code

    git clone https://github.com/kawakode/shareBuddy.git
cd shareBuddy

  2. Installez l’application

    scripts/build-app.sh --install

    ShareMan arrive dans le dossier Applications.

  3. Autorisez le réseau local

    Au premier scan, macOS vous demande l’accès au réseau local. Acceptez, sinon aucun serveur ne sera trouvé.

Pour l’outil en ligne de commande : swift build -c release, puis copiez .build/release/shareman dans /usr/local/bin.
